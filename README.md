# Metako Projex — Nexora concept demo

This is an independent, non-official website concept prepared by Nexora Technologies.

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the illustrative Unsplash images.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `metako-projex-concept-demo`.
2. Upload `index.html` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

## Important before sharing
- This is an independent concept, not Metako Projex's official website and not endorsed by the business.
- Project imagery is illustrative stock photography, not verified Metako project photography.
- Replace concept imagery with images approved by Metako before any production launch.
- The contact form only creates a `mailto:` draft; it does not collect, store or send form data.
- Business description and contact details were taken from Metako Projex's public website. Verify details again before production use.
